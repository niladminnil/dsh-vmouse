# 虚拟鼠标（virtual-mouse）

## 什么时候用

- 在本机做**桌面程序的点击 / 拖动 / 滚动测试**，需要反复操作界面。
- 需要操作界面，但**不想抢用户的真实鼠标**：用户正在用鼠标，或希望 agent 操作时用户仍能自由动鼠标。
- 以上场景**优先用虚拟鼠标**（`mcp__vmouse__*`）；真实鼠标工具（`mcp__desktop__mouse_*`）是它的兜底。

## 坐标怎么来

- 直接用 `mcp__desktop__screen_capture` 截图的**像素坐标**，图像里的 (x, y) 就是工具参数的 (x, y)。
- 坐标是物理像素（不是 DPI 缩放后的逻辑像素），不需要换算。
- 想先确认落点，可以用 `mcp__vmouse__move {x, y}` 只移光标；`mcp__vmouse__status` 能读回虚拟光标和真实指针的坐标。

## 标准流程

1. **截图定位**：`mcp__desktop__screen_capture`，在图上量出目标控件的像素坐标。
2. **虚拟点击**：`mcp__vmouse__click {x, y}`（右键传 `button: "right"`，双击传 `clicks: 2`）。
   - 拖动：`mcp__vmouse__drag {from_x, from_y, to_x, to_y}`。
   - 滚动：`mcp__vmouse__scroll {x, y, delta_y}`，正数向上、一格约 120。
3. **再截图确认**：确认界面真的变了，不要凭调用成功就认为点到了。
4. **失败时的回退顺序**：
   1. 先给 `click` 传 `hwnd`（窗口句柄）或 `window`（标题），把点击**直投到目标窗口**；
   2. 仍不行再传 `real: true`，**短暂使用真实指针**完成操作（会瞬移再复原）；
   3. 最后才退回 `mcp__desktop__mouse_*`（真实鼠标，需要窗口在前台，会抢占用户鼠标）。

## 图标语义

- **青色箭头 + AI 徽标**：agent 自己的虚拟光标，用户屏幕上看到它是正常现象。
- **点击波纹**：刚在这里点击/拖动/滚动过，可用来核对落点。
- 这只光标是独立的置顶浮层，不点得动（鼠标完全穿透），和真实指针互不影响。

## 注意事项与失败排查

- 虚拟鼠标**不移动真实指针**，所以用户随时可以继续用鼠标；不要因为"用户在用鼠标"就改用真实鼠标工具。
- 点击无反应时依次检查：
  1. `mcp__vmouse__status`：浮层是否可见、虚拟光标坐标是否就是目标坐标（坐标错 → 重新截图定位）；
  2. 目标程序是否属于**游戏 / Raw Input / DirectX·Vulkan 画布**类——这类不响应窗口消息，改用 `real: true`；
  3. 目标窗口是否以**管理员权限**运行——UIPI 限制下无法操作，只能请用户改用普通权限窗口；
  4. 还是不行，再按标准流程第 4 步的回退顺序处理。
- 滚动没反应时检查 `delta_y` 的符号（正数向上）和坐标是否落在可滚动区域内。
- 拖动的失败常常是起点压在了错误控件上：先截图核对 `from_x/from_y`。
- 坐标用整数物理像素；截图的坐标系与工具坐标系一致，不要叠加 DPI 缩放。
- 已实测可用：WinForms / Win32 控件、Chromium / Electron 窗口（包括 DSH 自身的聊天界面）。
